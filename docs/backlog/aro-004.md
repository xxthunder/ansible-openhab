# [ARO-004] Add CI: lint and molecule on push

**Status**: Open
**Priority**: Medium
**Component**: `.github/workflows/` (new)
**Related**: [ARO-001](aro-001.md) — builds the parity contract this item
merely calls; [ARO-003](aro-003.md) — decides which scenarios are worth running;
[ARO-005](aro-005.md) — a release policy that can gate on CI.

**Summary**:
As the role maintainer, I want lint and molecule to run automatically on push,
so that "verified" does not depend on remembering to run anything by hand.

**Description**:
The repo has no CI at all. Every check to date has been manual, and the
consuming project's publishing bar (HSH-010) expects a role to stand on its own
with tests that run without a person driving them.

Two jobs, in order of value. **Lint** — `yamllint` and `ansible-lint` — is cheap,
fast, and catches the class of mistake that is otherwise found by an agent that
cannot run `ansible-lint` at all from the consumer's session. **Molecule** needs
a Docker-capable runner; GitHub-hosted runners provide one, so the
`git-seeding` scenario should run there unchanged.

**This item is now only a workflow file.** [ARO-001](aro-001.md) owns everything
that makes a CI run and a local run the same run — `pyproject.toml` + `uv.lock`
pinning the toolchain, the molecule platform image pinned off `latest`, and
`scripts/test.sh` as the single entry point. A runner has Docker natively, so
there is no nesting to arrange: `uv sync --frozen`, then that script. If this
workflow ever needs its own version of a command, the contract has been broken
and the fix belongs in ARO-001, not here.

**Acceptance Criteria**:
- [ ] A workflow runs `yamllint` and `ansible-lint` on push and pull request.
- [ ] A workflow runs the molecule scenarios ARO-003 settles on.
- [ ] The workflow calls `scripts/test.sh` and defines no command of its own —
      the same entry point a developer runs locally.
- [ ] The badge or status is visible from `README.md`.
- [ ] A deliberately broken commit is shown to fail CI — a green pipeline that
      cannot go red proves nothing.

**Out of scope**:
- Publishing to Ansible Galaxy.
